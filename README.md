# About Me

Junior web developer focused on frontend and fullstack work. I'm comfortable on both sides of an app: React and Tailwind for the interface, and PHP/Laravel or Node/Express for the backend, with SQL and NoSQL databases behind them. I care about clean code, readable UIs, well-structured APIs, and shipping projects that actually work end to end. I keep improving through hands-on projects and team collaborations.

Currently open to **internships, junior roles, and collaborations** where I can contribute to real products and grow alongside a strong team.
